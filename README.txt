HOW TO PUT THIS ON GITHUB (no folders, nothing to arrange)
1. Unzip this file on your phone/computer.
2. Open your repo on github.com > Add file > Upload files.
3. Select ALL the files (54 files, all in one flat list) and drop/choose them. Wait for the uploads to finish.
4. Commit changes. Your site updates in about a minute (Settings > Pages must point to the main branch, root folder).
